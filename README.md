# 📁 Portfólio Web

Atividade de Desenvolvimento Web: portfólio pessoal desenvolvido para praticar HTML, CSS, PHP e JavaScript, rodando em ambiente local com XAMPP.

## 🛠️ Tecnologias

- HTML5
- CSS3
- PHP
- JavaScript
- XAMPP (ambiente local)

## 📂 Estrutura do projeto

```
portfolio-web/
├── assets/
│   ├── estilo.css
│   └── script.js
├── html/
│   ├── index.html
│   ├── minhahistoria.html
│   ├── minhahabilidade.html
│   ├── planos.futuros.html
│   ├── falecomigo.html
│   ├── indique.php
│   ├── processa.php
│   └── redesocial.php
└── images/
```

## 📄 Páginas

| Página | Arquivo | Descrição |
| ------ | ------- | --------- |
| Início | `html/index.html` | Página inicial do portfólio |
| Minha História | `html/minhahistoria.html` | Apresentação pessoal e trajetória |
| Minhas Habilidades | `html/minhahabilidade.html` | Habilidades e tecnologias que conheço |
| Planos Futuros | `html/planos.futuros.html` | Objetivos acadêmicos e profissionais |
| Fale Comigo | `html/falecomigo.html` | Formulário de contato |
| Indique | `html/indique.php` | Página em PHP para indicar o site |
| Processamento | `html/processa.php` | Script PHP que processa os dados enviados |
| Redes Sociais | `html/redesocial.php` | Página PHP com as redes sociais |

## 🚀 Como executar

1. Instale o [XAMPP](https://www.apachefriends.org/).
2. Copie a pasta `portfolio-web` para `C:\xampp\htdocs\`.
3. Abra o XAMPP Control Panel e clique em **Start** no Apache.
4. Acesse no navegador: `http://localhost/portfolio-web/html/index.html`

> ⚠️ O PHP não funciona abrindo o arquivo direto (`file:///`) nem pelo GitHub Pages. É preciso um servidor, como o Apache do XAMPP.
